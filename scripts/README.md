# Скрипты для диагностики

Небольшие bash-скрипты для разбора инцидентов в F5. Нужны `curl`, `jq` и Docker (для доступа к БД). Работают с системным bash macOS (3.2).

| Скрипт | Зачем |
|---|---|
| `healthcheck.sh` | Состояние всего окружения: `/health` трёх сервисов, обе БД, RabbitMQ, Prometheus (и какие цели не отвечают), активные алерты, Loki, Grafana. Код выхода 1, если недоступен сервис или инфраструктура |
| `trace.sh <request_id> [1h]` | Все строки лога одного запроса из gateway и сервиса в порядке времени. Ищет в Loki; если стек наблюдаемости не поднят — в `logs/*.log` |
| `outbox-status.sh` | Застряли ли события в outbox (employee, business) и вебхуки GitLab во входящей очереди: счётчики по статусам, возраст самой старой записи, последние ошибки. Код выхода 1, если есть FAILED или PENDING старше `MAX_PENDING_AGE` (60 с) |
| `snapshot.sh [30m]` | «Сохранить улики» перед перезапуском: health, ключевые метрики, алерты, ошибки из Loki, хвосты логов, `pg_stat_activity`, outbox, очереди RabbitMQ, контейнеры → `incidents/incident-<время>.tar.gz` |

## Примеры

```bash
# Пользователь прислал скриншот ошибки с request_id
./scripts/trace.sh 5d0c2e1a-8f3b-4c1e-9a77-1b2c3d4e5f60

# «Задача создалась, а в расширении не появилась»
./scripts/outbox-status.sh

# Перед рестартом упавшего сервиса
./scripts/snapshot.sh 1h

# В CI или cron: упасть, если окружение не готово
./scripts/healthcheck.sh >/dev/null || echo "окружение не готово"
```

Адреса по умолчанию — локальные порты из `observability/compose.yaml`. Их можно переопределить переменными `LOKI_URL`, `PROM_URL`, `ALERTMANAGER_URL`, `GRAFANA_URL`.

Архивы `incidents/` содержат логи и запросы к БД, поэтому они в `.gitignore`. Прежде чем приложить архив к тикету за пределами команды, посмотрите, что в нём.
